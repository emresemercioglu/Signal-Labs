## Frequently Asked Questions

### Do we need AI agents to use CIx?

+

No. CIx serves both human teams and AI agents. Whether you're using AI agents now or planning for future, CIx provides competitive intelligence for both. Human teams use the CIx dashboard and integrations. AI agents use the [CIx API, SDKs, and MCP server](https://usesignallabs.com/docs).

### What AI agent platforms does CIx integrate with?

+

CIx provides a [REST API](https://usesignallabs.com/docs) and [MCP server](https://usesignallabs.com/docs/mcp) that work with any AI agent platform: custom-built agents, agent frameworks (LangChain, AutoGPT), agent platforms (Salesforce AI, HubSpot AI), or LLM-powered agents (GPT-4, Claude, Gemini-based). We also ship native [JavaScript and Python SDKs](https://usesignallabs.com/docs/quickstart).

### How does CIx prevent AI hallucination of competitive information?

+

CIx provides verified, source-attributed competitive intelligence. Every claim has source and verification status. AI agents know what's verified vs. uncertain. This dramatically reduces hallucination risk for competitive information.

### Can we control what competitive information AI agents can access?

+

Yes. Configure competitive intelligence access, approved messaging, and guardrails. Control what AI agents can claim about competitors and what information they can access.

### How current is competitive intelligence for AI agents?

+

Real-time. CIx monitors competitors 24/7 and delivers updates via API. AI agents receive current competitive intelligence, not stale training data.

### Do AI agents need training on CIx?

+

No. CIx provides structured, documented APIs. AI agents integrate via standard API calls. No special training required - just standard API integration.

### What's the cost for AI agent API access?

+

API access is included in standard CIx plans. High-volume AI agent usage may require enterprise plans. Contact us for custom API rate limits and pricing.

### Can AI agents generate battlecards via API?

+

Yes. AI agents can request battlecard generation via API: specify competitor, focus (sales/marketing/product/leadership/landscape), and add custom instructions. Battlecard generated and delivered via API. See the [quickstart guide](https://usesignallabs.com/docs/quickstart) or the [API launch announcement](https://usesignallabs.com/blog/introducing-signal-labs-api-mcp-server) for code examples.
