## Frequently Asked Questions

### How is CIx different from dedicated win/loss tools like Clozd?

+

Win/loss interview tools (Clozd, Wynter) provide deep qualitative insights from buyer interviews. CIx provides competitive intelligence and pattern detection across ALL deals. They're complementary: CIx integrates with Clozd to combine quantitative data (all deals) with qualitative insights (interview sample).

### Do we need to interview buyers for win/loss analysis?

+

Not required but recommended. CIx analyzes competitive win/loss patterns from CRM data automatically. Add interview data for deeper insights. Many teams start with CRM analysis, add interviews for critical competitors or segments.

### How does CIx capture competitive loss reasons?

+

Multiple methods: 1) Integration with CRM competitive fields, 2) Rep input via CIx interface, 3) Conversation intelligence from Gong/Chorus, 4) Win/loss interview integration. You choose methods based on your workflow.

### Can we track win rates by sales rep?

+

Yes. Track competitive performance by rep, team, region, segment, deal size, industry. Identify top performers in competitive deals and understand what makes them successful.

### How long until we see actionable insights?

+

Initial insights appear within days as CIx analyzes existing CRM data. Pattern detection becomes more robust with more data (typically actionable patterns within 30 days). Immediate value from competitor-specific win rate tracking.

### What if our loss reason data is incomplete?

+

Common challenge. CIx can help capture better data going forward: simple rep input forms, Gong/Chorus automatic capture, integration with existing processes. Start improving data quality while analyzing what you have.
